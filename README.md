# First Step

Persönlicher Langzeit-Tracker für 180 Tage (Start: 02.11.2026): Gym, Wasser, Schritte, Schlaf, Verzicht auf Süßigkeiten/Fast Food und ein Monatsgewicht.

## Dateien
- `index.html` – die komplette App (eine Datei, keine Abhängigkeiten)
- `first-step-logo.svg` – Logo und Tab-Symbol

## Veröffentlichen mit GitHub Pages
1. Repository anlegen und die Dateien im Hauptverzeichnis ablegen.
2. Settings → Pages → „Deploy from a branch" → Branch `main`, Ordner `/ (root)`.
3. Die Seite ist danach unter `https://<benutzername>.github.io/<repo>/` erreichbar.

## Daten
Die Einträge werden nur im Browser (localStorage) des jeweiligen Geräts gespeichert, es gibt keine Synchronisation. Mit „Als CSV exportieren" kannst du jederzeit eine Sicherung erstellen. Beim Löschen der Browserdaten gehen die Einträge verloren.
